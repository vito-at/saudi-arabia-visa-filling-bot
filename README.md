# Бот для оформления туристических e-виз в Саудовскую Аравию

Программа для турагентства: вы отправляете фото паспорта клиента, она распознаёт
данные, показывает их вам на подтверждение, заполняет анкету на портале и
останавливается на странице проверки/оплаты. **Оплату и финальную отправку делаете вы.**
Капчу, SMS/OTP и проверки «вы не робот» программа не обходит — ставит паузу и ждёт вас.

## Что готово сейчас

| Этап | Статус |
|---|---|
| 1. Вопросы о структуре анкеты | ждём от вас запись `codegen` и скриншоты (см. [docs/FORM_RECORDING.md](docs/FORM_RECORDING.md)) |
| 2. Распознавание паспорта (`ocr/`) | **готово**, нужно проверить на ваших фото |
| База заявок и шифрование (`db/`) | **готово** |
| Словари выпадающих списков (`filler/matching.py`, `config/dictionaries.yaml`) | **готово**, дополним по порталу |
| 3. Заполнение анкеты (`filler/`) | после записи `codegen` |
| 4. Telegram-бот (`bot/`) | после этапа 3 |

## Структура проекта

```
saudi-arabia-visa-filling-bot/
├── bot/                    Telegram-бот (этап 4)
├── ocr/                    распознавание паспорта
│   ├── mrz.py              чтение MRZ (fastmrz → passporteye) + контрольные суммы
│   ├── vision.py           поля вне MRZ через Claude API (строгий JSON)
│   ├── translit.py         единая латиница (паспорта Узбекистана: Oʻ/Gʻ, KH/X ...)
│   ├── images.py           обрезка страницы паспорта, вырезание лица, сжатие
│   ├── pipeline.py         сверка MRZ и vision, пометка «требует проверки»
│   └── cli.py              проверка на своих фото без бота
├── filler/                 заполнение анкеты (этап 3)
│   └── matching.py         выбор пункта выпадающего списка по словарю
├── db/
│   ├── database.py         SQLite: заявки, статусы, файлы (данные зашифрованы)
```

## Установка на Windows 10/11 — пошагово

Делается один раз. Все команды вводятся в **PowerShell**
(Пуск → введите «PowerShell» → Enter).

### Шаг 1. Установите Python 3.11 или новее

1. Откройте https://www.python.org/downloads/ и скачайте последнюю версию Python 3.
2. Запустите установщик. **Обязательно поставьте галочку «Add python.exe to PATH»**
   внизу первого окна, затем нажмите «Install Now».
3. Проверьте в PowerShell:
   ```powershell
   python --version
   ```
   Должно показать `Python 3.11.x` или выше.

### Шаг 2. Установите Tesseract OCR (читает MRZ)

1. Скачайте установщик для Windows: https://github.com/UB-Mannheim/tesseract/wiki
   (файл `tesseract-ocr-w64-setup-...exe`).
2. Установите в папку по умолчанию `C:\Program Files\Tesseract-OCR`.
3. Скачайте файл модели MRZ `mrz.traineddata`:
   https://github.com/DoubangoTelecom/tesseractMRZ/raw/master/tessdata_best/mrz.traineddata
   (размер около 11 МБ).
4. Положите его в папку `C:\Program Files\Tesseract-OCR\tessdata\`
   (Windows попросит права администратора — нажмите «Продолжить»).

### Шаг 3. Скачайте проект

Если у вас установлен Git:
```powershell
cd $HOME\Documents
git clone https://github.com/vito-at/saudi-arabia-visa-filling-bot.git
cd saudi-arabia-visa-filling-bot
```
Без Git: на странице репозитория нажмите **Code → Download ZIP**, распакуйте в
`Документы`, затем в PowerShell перейдите в папку:
```powershell
cd $HOME\Documents\saudi-arabia-visa-filling-bot
```

### Шаг 4. Создайте виртуальное окружение и установите библиотеки

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m playwright install chromium
```

> Если PowerShell пишет «выполнение сценариев отключено», один раз выполните
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, ответьте `Y` и повторите
> `.\.venv\Scripts\Activate.ps1`.

**Каждый раз** перед работой с программой открывайте PowerShell в папке проекта и
активируйте окружение командой `.\.venv\Scripts\Activate.ps1` (в начале строки
появится `(.venv)`).

### Шаг 5. Настройте файл .env

1. Скопируйте образец:
   ```powershell
   copy .env.example .env
   ```
2. Сгенерируйте ключ шифрования:
   ```powershell
   python -m db.keygen
   ```
   Скопируйте выведенную строку.
3. Откройте `.env` в Блокноте (`notepad .env`) и заполните:
   * `FILE_ENCRYPTION_KEY=` — ключ из п.2. **Сохраните его копию в надёжном месте**
     (менеджер паролей): без него зашифрованные данные не открыть.
   * `ANTHROPIC_API_KEY=` — ключ Claude API (https://console.anthropic.com → API Keys).
   * `TESSERACT_CMD` и `TESSDATA_DIR` — оставьте как есть, если ставили Tesseract в папку
     по умолчанию.
   * `RETENTION_DAYS=` — через сколько дней удалять фото паспортов (по умолчанию 14).
   * `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_ID` — понадобятся на этапе 4.

### Шаг 6. Ограничьте доступ к папке с данными

Папка `data\` появится при первом запуске. Чтобы доступ к ней был только у вашей
учётной записи Windows, выполните (один раз, после первого запуска):
```powershell
icacls data /inheritance:r /grant:r "$($env:USERNAME):(OI)(CI)F"
```
Дополнительно рекомендуем включить шифрование диска BitLocker
(Параметры → Конфиденциальность и защита → Шифрование устройства).

### Шаг 7. Проверьте, что всё установилось

```powershell
python -m pytest -q
```
Все тесты должны пройти (`passed`).

## Проверка распознавания на ваших фото

```powershell
python -m ocr.cli "C:\путь\к\фото_паспорта.jpg"
```
Несколько фото сразу:
```powershell
python -m ocr.cli фото1.jpg фото2.jpg фото3.jpg
```
Полезные ключи:
* `--no-vision` — только MRZ, без Claude API (бесплатно, быстро);
* `--save-crops out` — сохранить обрезанную страницу паспорта и лицо в папку `out`
  (**эти файлы не шифруются — удалите их после проверки**);
* `--json` — вывести все данные в JSON.

Как читать результат:

| Метка | Значение |
|---|---|
| `OK` | MRZ с верной контрольной суммой, совпадает с визуальной зоной |
| `VIS` | поле есть только в визуальной зоне (место рождения, дата выдачи, орган) |
| `CHECK` | **требует проверки**: источники расходятся или не сошлась контрольная сумма |
| `----` | не распознано |

### Советы по фото

* Снимайте разворот с фото целиком, без бликов, при дневном свете.
* В Telegram отправляйте фото **как файл** (скрепка → Файл), а не как «фото» — так
  Telegram не сжимает изображение и MRZ читается надёжнее.

## Как работает распознавание

1. Страница паспорта находится на фото и выравнивается.
2. MRZ читается через `fastmrz`, при неудаче — через `passporteye`. Проверяются все
   контрольные суммы ICAO 9303. Типичные ошибки OCR (O↔0, I↔1, S↔5, B↔8) исправляются
   **только если после исправления сходится контрольная сумма**, и такие поля
   помечаются.
3. Claude (vision) читает всю страницу и возвращает строгий JSON: в том числе место
   рождения, дату выдачи и орган выдачи, которых нет в MRZ.
4. Для полей, которые есть и в MRZ, и на странице, значения сравниваются. Если
   расходятся — поле помечается «требует проверки», в карточке будут оба варианта.
5. **Имя и фамилия латиницей всегда берутся из MRZ** (для паспортов Узбекистана это
   важно: `Gʻ`/`Oʻ` в MRZ пишутся как `G`/`O`). Для сравнения с визуальной зоной
   используется «ключ», склеивающий разные системы транслитерации (KH/X, YU/IU, ZH/J…).
6. Проверяется срок действия паспорта (предупреждение, если осталось меньше 6 месяцев).

## Безопасность данных

* Фото паспортов, лица и скриншоты хранятся **только в зашифрованном виде**
  (`data\files\*.enc`), расшифровываются в памяти.
* Персональные данные в базе SQLite зашифрованы тем же ключом; открыто хранятся только
  номер заявки, статус и даты.
* Фото и скриншоты автоматически удаляются через `RETENTION_DAYS` дней; у завершённых
  заявок стираются и персональные данные.
* Все ключи — в `.env`, этот файл не попадает в Git (см. `.gitignore`).
* Доступ к боту будет только с `TELEGRAM_ADMIN_ID` (этап 4).
* Фото паспорта отправляется в Claude API для распознавания. Отметьте это в согласии
  клиента на обработку персональных данных.
